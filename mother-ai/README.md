# NGF Mother AI

NGF Mother AI is the orchestration and intelligence layer for the NGF ecosystem.

Lifecycle:

RESEARCH -> KNOWLEDGE -> PLAN -> BUILD -> TEST -> DIAGNOSE -> FIX -> DEPLOY -> OBSERVE -> IMPROVE

OLMo is the controllable model layer inside Mother AI.

Mother AI will coordinate research, structured knowledge, training, agents, website creation, regression testing, deployment, analytics, and continuous improvement.

Large model weights, checkpoints, datasets, and generated artifacts must not be committed to Git.
